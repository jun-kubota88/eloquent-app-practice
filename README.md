## 概要
COACHTECH 教材 Tutorial 9-4「Eloquent ORM ハンズオン演習」で作成した成果物です。

## 使用技術
- PHP 8.x
- Laravel 10.x
- Eloquent ORM
- MySQL

## 学んだこと
- Eloquent モデルを使ったCRUD操作（Model::all(), create(), update(), delete()）
- $fillable を使ったマスアサインメント対策の必要性
- リソースコントローラ（index/create/store/edit/update/destroy）の役割
